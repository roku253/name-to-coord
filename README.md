# name-to-coord

静的 `index.html` + `token-gate.js`。ポータル側のトークンで表示します。画面上は入力フォーム・結果表示と、末尾の**架空サイト注記**のみです（算出ロジックはこの README に記載）。

## 表示ロジック（開発メモ）

- **大倉翔太**（表記ゆれ: 大倉 翔太・スペース有無など）は、座標表示のほか送信ログ **`Log_9901`**（`#Log_9901`）を返します。2016年事件の犯人側の痕跡として設計されています。
- **それ以外の名前**は、正規化後の文字列をキーに **FNV-1a 風ハッシュ**で緯度・経度を決めます。同一キーなら常に同じ座標です（日本のおおよその矩形内）。
- 出力は Gougle Map の検索欄（`緯度, 経度`）または `67B_MUNAGI` デバッグ検索にそのまま渡せます。

## 公開時の注意（フィクション）

本作は謎解き用の架空サイトです。必要に応じてポータル側や利用規約などで、サービス名・地名・人物名がフィクションである旨を明示してください。

## 設定

`token-gate.js` の `TOKEN_GATE_ORIGIN` を本番ポータルに合わせてください。
