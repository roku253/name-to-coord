# name-to-coord

静的 `index.html` + `token-gate.js`。ポータル側のトークンで表示します。画面上は仕様説明を載せず、プレイ用の最小 UI のみです。

## 表示ロジック（開発メモ）

- **水瀬ハルト**（表記ゆれ: かな・ローマ字組み合わせなど）は固定で **`35.420000, 138.910000`** を返します。
- **それ以外の名前**は、正規化後の文字列をキーに **FNV-1a 風ハッシュ**で緯度・経度を決めます。同一キーなら常に同じ座標です（日本のおおよその矩形内）。
- 出力は Gougle Map の検索欄（`緯度, 経度`）または `?lat=&lng=` にそのまま渡せます。

## 設定

`token-gate.js` の `TOKEN_GATE_ORIGIN` を本番ポータルに合わせてください。
